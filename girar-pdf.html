Girar PDF

Corrija documentos digitalizados de lado ou de cabeça para baixo. Seus arquivos não são enviados para nenhum servidor. Todo o processamento acontece dentro do seu navegador.

Publicidade

Como usar: girar pdf

  1. Escolha o PDF.
  2. Selecione o giro: 90° para a direita, 180° ou 90° para a esquerda.
  3. Defina se vale para todas as páginas ou só para algumas (por exemplo “1, 3-5”).
  4. Toque em “Processar” e baixe.

Dicas

  • Para girar páginas diferentes em direções diferentes, rode a ferramenta duas vezes ou use Organizar páginas.

Perguntas frequentes

O giro é permanente?

Sim, o novo arquivo é salvo já com as páginas giradas, e abre assim em qualquer leitor de PDF.

A qualidade muda?

Não. O conteúdo não é recomprimido.
