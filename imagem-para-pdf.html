Imagens para PDF

Junte fotos de documentos, comprovantes e prints em um só PDF. Seus arquivos não são enviados para nenhum servidor. Todo o processamento acontece dentro do seu navegador.

Cada imagem vira uma página. Reordene com as setas.

Publicidade

Como usar: imagens para pdf

  1. Adicione as imagens (JPG, PNG ou WebP).
  2. Reordene com as setas: cada imagem vira uma página.
  3. Escolha página A4 ou do tamanho da imagem, e a margem.
  4. Toque em “Processar” e baixe o PDF.

Dicas

  • Para documentos, A4 com margem pequena deixa o PDF pronto para imprimir.
  • Imagens muito grandes são reduzidas automaticamente para manter o arquivo leve.

Perguntas frequentes

Quais formatos de imagem são aceitos?

JPG, PNG e WebP.

As fotos do celular saem na orientação certa?

Sim, a rotação gravada pela câmera é respeitada.
