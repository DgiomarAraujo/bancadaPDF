PDF para texto

Copie todo o texto de um PDF de uma vez, sem formatação, para colar em outro programa, procurar palavras ou guardar como anotação. O arquivo não é enviado para nenhum servidor.

Funciona em PDFs com texto. Páginas digitalizadas (imagem) não têm texto para extrair e não passam por OCR.

Publicidade

Como usar: pdf para texto

  1. Toque em “Escolher PDF” ou arraste o arquivo para a área indicada.
  2. Se quiser, deixe marcada a opção que identifica o início de cada página.
  3. Toque em “Processar” e baixe o arquivo .txt.

Dicas

  • Funciona melhor em PDFs gerados no computador, como faturas, contratos e relatórios. Tabelas viram linhas de texto separadas por espaços.
  • Se o PDF veio de um scanner ou de uma foto, não há texto para extrair e esta ferramenta não faz OCR.
  • Para um arquivo editável com títulos e parágrafos, use PDF para Word.

Perguntas frequentes

Por que o resultado veio vazio?

O PDF provavelmente é uma digitalização: cada página é uma imagem, sem texto de verdade. Seria preciso OCR, que esta ferramenta não faz.

A formatação é mantida?

Não. O resultado é texto puro. Parágrafos e linhas em branco são aproximados pela posição do texto na página.

Meus arquivos são enviados para algum servidor?

Não. O processamento acontece no seu navegador e os arquivos não saem do aparelho.
