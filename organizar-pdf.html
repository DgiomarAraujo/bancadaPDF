Organizar páginas do PDF

Veja todas as páginas em miniatura e arrume o documento com alguns toques. Seus arquivos não são enviados para nenhum servidor. Todo o processamento acontece dentro do seu navegador.

Publicidade

Como usar: organizar páginas

  1. Escolha o PDF e aguarde as miniaturas aparecerem.
  2. Use as setas para mover uma página, o botão de giro para virar e o X para excluir.
  3. Toque em “Processar” para gerar o PDF na nova ordem.

Dicas

  • Em PDFs muito longos as miniaturas aparecem aos poucos; você já pode começar a arrumar o início.
  • Digitalizou uma folha de cabeça para baixo? Gire só aquela página.

Perguntas frequentes

Existe limite de páginas?

Não há limite fixo, mas documentos com centenas de páginas podem demorar para gerar as miniaturas em celulares simples.

As miniaturas alteram o arquivo?

Não, são só uma prévia. O resultado usa as páginas originais.
